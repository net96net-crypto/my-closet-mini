# MY CLOSET MINI

ארון בגדים אישי ופשוט לאייפון, בעברית.

- הוספת בגדים עם תמונה ותיאור, או עם תיאור בלבד
- קטגוריות, חיפוש, עריכה ומחיקה
- גיבוי ושחזור בעזרת קובץ אחד

**פרטיות:** הקוד כאן ציבורי, אבל הבגדים, התמונות והתיאורים נשמרים רק באייפון של המשתמשת (IndexedDB בדפדפן). הם לא עולים לפרויקט הזה ולא נשלחים לשום שרת.

שלב הבא: סטייליסטית AI. מפתח ה-API יישמר בצד השרת, ולא באפליקציה.
